# 三国志策略游戏

一款基于HTML5的单机策略游戏，采用回合制玩法，背景设定在三国时期。

## 项目状态

**当前阶段：阶段1 - 基础框架与简化地图** ✅

已完成功能：
- ✅ 项目基础架构（HTML/CSS/JS模块化）
- ✅ 核心数据结构（游戏状态、城池、武将、势力）
- ✅ 简化版2D地图渲染
- ✅ 地图交互（缩放、拖动、点击城池）
- ✅ 基础UI框架（信息栏、控制按钮、信息面板）
- ✅ 游戏状态保存/加载（LocalStorage）
- ✅ 回合推进机制

## 如何运行

### 方法1：使用本地服务器（推荐）

由于使用了ES6模块，需要通过HTTP服务器运行：

```bash
# 使用Python（如果已安装）
python -m http.server 8000

# 或使用Node.js的http-server（需要先安装：npm install -g http-server）
http-server -p 8000

# 或使用PHP（如果已安装）
php -S localhost:8000
```

然后在浏览器中访问：`http://localhost:8000`

### 方法2：使用VS Code Live Server

1. 安装VS Code的"Live Server"扩展
2. 右键点击 `index.html`
3. 选择"Open with Live Server"

## 功能说明

### 当前可用功能

1. **地图系统**
   - 显示三国地图（简化版2D网格）
   - 城池标记和颜色区分（按势力）
   - 鼠标拖拽平移地图
   - 鼠标滚轮/按钮缩放地图
   - 点击城池查看详细信息

2. **势力系统**
   - 三个初始势力：蜀、魏、吴
   - 玩家扮演蜀国
   - 势力资源管理（金钱、粮食、木材）

3. **城池系统**
   - 基础城池属性（人口、守军、城墙等）
   - 城池产出计算
   - 城池列表查看

4. **武将系统**
   - 初始武将：刘备、关羽、张飞、曹操、孙权
   - 武将属性（武力、智力、统率、魅力等）
   - 武将列表查看

5. **回合制系统**
   - 回合推进
   - 季节变化（春夏秋冬）
   - 年份推进
   - 资源自动更新

6. **UI系统**
   - 顶部信息栏（日期、势力、资源）
   - 底部控制按钮
   - 信息面板（可拖拽关闭）
   - 游戏保存/加载

## 操作说明

- **地图拖动**：鼠标左键拖拽
- **地图缩放**：鼠标滚轮或右上角按钮
- **查看城池**：点击地图上的城池圆点
- **查看城池列表**：点击底部"城池"按钮
- **查看武将**：点击底部"武将"按钮
- **下一回合**：点击底部"下一回合"按钮
- **保存游戏**：点击"保存"按钮
- **加载游戏**：点击"加载"按钮
